The Smart Expense Tracker is a Python-based data management and analytics project designed to help users record, manage, filter, and analyze their daily expenses.

The project uses Python, Pandas, NumPy, Matplotlib, and Seaborn to perform expense calculations and generate meaningful visual reports.

Key Features

Add Expenses: Record new expenses with date, amount, category, and description.

Expense Summary: Calculate total expenses and category-wise spending.

Filter Expenses: Search expenses by date, category, or date range.

Data Analytics: Generate statistical summaries, including average, maximum, minimum, and total expenses.

Data Visualization: Create bar charts, pie charts, line charts, and histograms.

Monthly Analysis: Analyze monthly spending trends and compare category-wise expenses.

Data Storage: Save updated expense records into a CSV file.

Technologies Used

Python

Pandas

NumPy

Matplotlib

Seaborn



Objective: To build a simple expense management system while applying Python programming, object-oriented programming, data manipulation, statistical analysis, and data visualization concepts.
